# DARK CONTROL PRO

لوحة تحكم لإدارة عدة بوتات Telegram ومزودي الـ API والخدمات والطلبات والأرصدة.
تعمل على Cloudflare Workers، وتخزن البيانات في SQLite داخل Durable Object، ولا تحتاج إلى GitHub.

## النشر (مرة واحدة)

1. ادخل مجلد المشروع ونفّذ: `npm install`
2. سجّل الدخول إلى حساب Cloudflare: `npx wrangler login` (يفتح المتصفح للتأكيد)
3. أنشئ سرّين عشوائيين وأضفهما إلى Cloudflare:
   - `npx wrangler secret put MASTER_KEY`: مفتاح تشفير التوكنات ومفاتيح المزودين (32 حرفاً على الأقل)
   - `npx wrangler secret put SETUP_TOKEN`: رمز إنشاء حساب المالك مرة واحدة
   - لتوليد قيمة عشوائية: `openssl rand -hex 32`
4. انشر المشروع: `npx wrangler deploy`
5. افتح الرابط الذي يظهر بعد النشر، وأنشئ حساب المالك باستخدام `SETUP_TOKEN`.

## بعد النشر

- أضف مزود الـ API، ثم اختبر الاتصال لتعرف الرصيد المتاح.
- أضف البوت بتوكنه من BotFather، ثم اضغط «تشغيل الاستقبال». يُضبط الـ Webhook تلقائياً لكل بوت على رابط اللوحة نفسه.
- حقل «ربط الحقول» في نموذج المزود يحدد أسماء الحقول والأوامر. عدّله ليطابق الوثائق الرسمية لذلك المزود.

## تنبيهات مهمة

- لا تغيّر `MASTER_KEY` بعد إضافة البوتات أو المزودين، لأن التوكنات المشفّرة لن تُفك بعد ذلك.
- `SETUP_TOKEN` لا يُستخدم بعد إنشاء المالك، ويمكن حذفه من أسرار Cloudflare.
- تعديل الرصيد يقتصر على المالك، وتُسجَّل كل حركة في دفتر الرصيد.
